## 5. MATHEMATICAL FORMULATIONS
Include these exact equations in the methodology and implementation section:

1. **Dense Cosine Semantic Similarity:**
   $$\text{Sim}_{\text{dense}}(Q, D_i) = \frac{\mathbf{e}_q \cdot \mathbf{e}_{d_i}}{\|\mathbf{e}_q\|_2 \|\mathbf{e}_{d_i}\|_2} = \frac{\sum_{k=1}^{384} e_{q,k} \cdot e_{d_i,k}}{\sqrt{\sum_{k=1}^{384} e_{q,k}^2} \sqrt{\sum_{k=1}^{384} e_{d_i,k}^2}}$$
   where $\mathbf{e}_q, \mathbf{e}_{d_i} \in \mathbb{R}^{384}$ are generated by Siamese BERT (`all-MiniLM-L6-v2`).

2. **Sparse Lexical Scoring (BM25Plus with document length compensation):**
   $$\text{Score}_{\text{BM25+}}(Q, D_i) = \sum_{t \in Q} \text{IDF}(t) \cdot \left[ \frac{f(t, D_i) \cdot (k_1 + 1)}{f(t, D_i) + k_1 \cdot \left(1 - b + b \cdot \frac{|D_i|}{\text{avgdl}}\right)} + \delta \right]$$
   where $k_1 = 1.5, b = 0.75, \delta = 1.0$, and $\text{IDF}(t) = \ln \left( \frac{N - n(t) + 0.5}{n(t) + 0.5} + 1 \right)$.

3. **Reciprocal Rank Fusion (RRF) with Temporal Encounter Boost:**
   $$\text{RRF}(D_i) = \frac{1}{60 + r_{\text{lex}}(D_i)} + \frac{1}{60 + r_{\text{dense}}(D_i)} + \text{Boost}_{\text{temporal}}(D_i)$$
   $$\text{Boost}_{\text{temporal}}(D_i) = 0.005 \times \exp\left( -0.05 \times \Delta t_{\text{days}} \right)$$

4. **Zero-Hallucination Decision Gate:**
   $$\text{Decision}(Q) = \begin{cases} 
   \text{Route Top-8 passages to LLM synthesis}, & \text{if } \max_{i} \text{RRF}(D_i) \ge 0.015 \\
   \text{Abstain immediately with } \texttt{STATUS = NO\_EVIDENCE}, & \text{if } \max_{i} \text{RRF}(D_i) < 0.015
   \end{cases}$$

The system consists of 6 sequential stages:
1. **Ingestion & Safe Harbor De-Identification:** Regex pipeline scrubbing 18 HIPAA identifier classes (names, MRNs, dates, locations) while preserving clinical semantics.
2. **Sliding-Window Chunking:** Semantic segmentation into 512-token chunks with 64-token overlap.
3. **Dual-Stream Indexing:**
   - Dense Stream: 384-dimensional vector embeddings via `all-MiniLM-L6-v2`.
   - Sparse Stream: Clinical term tokenization and inverted indexing via BM25Plus.
4. **SQLite Vector Persistence:** Stores chunks and precomputed embeddings in `embedding_cache` (SHA-256 passage hash $\to$ 1,536-byte packed float32 blob).
5. **Hybrid RRF Fusion & Temporal Boost:** Re-ranks passages combining lexical accuracy and semantic recall.
6. **Citation Entailment & Physician Station:** Verifies claim entailment (cosine score $\ge 0.72$), checks CDSS watchdog rules, and renders grounded citations (`Ref 1`, `Ref 2`) to the React dashboard.
